# Study Night – Flashcards App

This is my submission for the **Udacity Front-End JavaScript Nanodegree (Project 4 - Testing and Optimization)**.

## 📚 Project Overview

Study Night is a web app that allows users to:

- Create and name study sets
- Add and review digital flashcards
- Navigate between Home, About, and Card Sets pages

The app is fully tested with **Cypress E2E tests**, and all tests pass successfully.

---

## 🧩 Technologies Used

- HTML5, CSS3, JavaScript (ES Modules)
- Parcel Bundler
- Cypress for End-to-End testing
- Gulp for running the development server
